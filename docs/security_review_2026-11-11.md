### Fix 1 — price-cache path injection

`_disk_cache_path()` now derives the filename from a SHA-256 digest of the
normalized ticker instead of the raw ticker:

```python
digest = hashlib.sha256(normalized.encode("utf-8")).hexdigest()[:24]
return DISK_CACHE_DIR / f"{digest}_{start}_{end}.json"
```

The tainted string never reaches the filesystem path, the filename is still
deterministic/ticker-specific, and an empty ticker is rejected. `_disk_cache_get`
degrades to `None`; `_disk_cache_set` skips the write. New tests cover a
traversal payload, determinism, ticker separation and the empty-ticker case.

Trade-off: existing `data/price_cache/<TICKER>_*.json` files are no longer
read (the cache is a disposable local artifact), so the next price-heavy run
will refetch once. No database or API change.

### Findings 2–4 — mobile transitive dependencies

All three Dependabot alerts are in `mobile/package-lock.json`, and all are
transitive **build/dev** dependencies (Expo CLI, ESLint config, Jest config),
not the Python backend and not first-party runtime code. `npm audit --omit=dev`
still lists them because Expo ships its CLI under the `expo` dependency, but
the CLI/zod/glob code is not part of the app bundle generated by Metro.

- `zod@4` is a major upgrade; forcing it with an override can break the
  Expo/ESLint tooling. The correct fix is an Expo SDK/tooling upgrade, not a
  one-line bump.
- `glob@14` is also a major jump; `glob@7` used by Jest is outside the
  advisory range.
- `deepmerge` has **no patched release**. The exposure is a build-time
  `mergeObject` of configuration objects; exploiting it needs
  attacker-controlled keys in the build config, which is not the threat model
  of a local build. Keep it until Jest/Expo replace it.

Recommendation: a dedicated **mobile dependency upgrade session**
(`expo`/`@expo/cli`, `eslint-config-expo`, `jest-expo`, zod/glob overrides)
with a full `npm ci && npm test && npm run typecheck && npm run lint && expo
export` run. Do not force `zod@4` in the backend verification session.
